# CapJet Loggbok

Enkel timelogg for CapJet-traineer med supervisor-signatur på skjermen og PDF til permen.

**Åpne appen:** https://supersaiyan01.github.io/capjet-logg/

## Kom i gang

1. Åpne lenken i Safari (iPhone) eller Chrome (Android).
2. Legg den på hjemskjermen:
   - iPhone: Del → Legg til på Hjem-skjerm
   - Android: ⋮ → Legg til på startskjermen
3. Fyll inn navn og firma første gang.
4. Registrer timer etter hvert skift.
5. Få supervisor til å godkjenne under **Godkjenning**. Supervisor kan justere timer og signerer med fingeren, gjerne med telefonen sidelengs.
6. Ta sikkerhetskopi etter hver tur (**Rapporter → Ta sikkerhetskopi**) og send den til deg selv.

## Godt å vite

- Alt lagres bare på din telefon. Ingen andre ser timene dine, og ingenting sendes noe sted.
- Mister du telefonen eller sletter nettleserdata uten sikkerhetskopi, er loggen borte. Ny telefon: åpne appen og trykk **Importer**.
- Appen virker uten nett etter første gang den er åpnet.
- Signaturen dokumenterer at supervisor har gått gjennom timene. Den er ikke en juridisk e-signatur, og erstatter ikke en loggbok arbeidsgiveren din krever.
- Hold kommentarene generelle hvis prosjektinformasjon er konfidensiell.
