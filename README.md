# CapJet Loggbok – kollega-versjon

Frittstående timelogg med supervisor-signatur. Trenger ikke Claude, konto eller innlogging.
Alt lagres bare på telefonen til den som bruker den.

## Filer

| Fil | Hva den gjør |
|---|---|
| `index.html` | Selve appen (PDF-verktøy er bygget inn, virker uten nett) |
| `manifest.webmanifest` | Navn og ikon når appen legges på hjemskjermen |
| `sw.js` | Gjør at appen åpner uten nett etter første besøk |
| `icon-192.png`, `icon-512.png` | App-ikon |

## Legg den ut gratis på GitHub Pages (ca. 5 minutter)

1. Gå til github.com, logg inn og trykk **New repository**.
2. Kall det for eksempel `capjet-logg`. Velg **Public**. Trykk **Create repository**.
3. Trykk **uploading an existing file**, dra inn alle filene fra denne mappen (ikke selve mappen), og trykk **Commit changes**.
4. Gå til **Settings → Pages**. Under *Branch* velger du `main` og `/ (root)`, og trykker **Save**.
5. Vent 1–2 minutter. Lenken blir: `https://BRUKERNAVN.github.io/capjet-logg/`

Send den lenken til kollegene. Repoet inneholder bare app-koden – ingen timer eller navn,
for alt den enkelte skriver blir liggende på egen telefon.

## Oppdatere appen senere

Last opp ny `index.html` i samme repo (erstatt den gamle). Kollegene får den nye versjonen
neste gang de åpner appen med nett. Dataene deres blir liggende.

## Kort til kollegene (kan kopieres)

> Her er en loggbok for CapJet-timer med supervisor-signatur: [lenke]
> 1. Åpne lenken i Safari (iPhone) eller Chrome (Android) og legg den på hjemskjermen.
> 2. Fyll inn navn og firma første gang.
> 3. Registrer timer etter hvert skift, og få supervisor til å signere under Godkjenning.
> 4. Ta sikkerhetskopi etter hver tur (Rapporter → Ta sikkerhetskopi) og send den til deg selv.
> Alt ligger bare på din telefon. Ingen andre ser timene dine.

## Viktig å vite

- **Sikkerhetskopi er den enkeltes ansvar.** Mister de telefonen eller sletter nettleserdata uten kopi, er loggen borte.
- **iPhone:** Legg appen på hjemskjermen. Safari kan ellers slette lagrede data for nettsider som ikke er brukt på en stund.
- **Signaturen** dokumenterer at supervisor har gått gjennom timene. Den er ikke en juridisk e-signatur.
- Sikkerhetskopier fra din Claude-versjon kan leses inn her, og omvendt.
